PRISM CODE — SITE 

Esta versão usa somente HTML, CSS e JavaScript comum.

ARQUIVOS
- index.html: conteúdo e estrutura do site.
- style.css: identidade visual, temas e responsividade.
- script.js: tema claro/escuro, menu mobile e animações.
- assets/: logos e símbolo oficial da Prism Code.

ACESSIBILIDADE
O botão acima do atalho do Instagram abre os recursos de acessibilidade:
- tamanho do texto;
- alto contraste;
- destaque de links;
- pausa de animações;
- redefinição das preferências.

As escolhas ficam salvas no próprio navegador do visitante.
